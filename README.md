# 🗃️ Meme Vault

> An immersive, cinematic media collection vault for saving memes, soundboard audio, and video reels. Inspired by high-impact magazine/hero carousel interactions with fluid transitions and tactile sound pads.

![Meme Vault Preview](https://i.imgflip.com/1ur9b0.jpg)

## ✨ Features

- **🎬 Showcase View (Hero Slider)**: Full-bleed carousel presentation with background cross-fades, bold kinetic typography, glassmorphic upcoming cards, and progress tracking.
- **📁 Collection Grid**: Categorized masonry layout for browsing all saved media, tagging, filtering, and favoriting.
- **🔊 Soundboard**: Interactive, tactile audio pads with animated waveform visualizers for instant reaction sounds.
- **⚡ Drag & Drop Ingest**: Drop images, audio clips, or video reels directly into the vault.
- **🔍 Instant Search**: Filter quickly across names, tags, and media categories.
- **💾 Local-First Persistence**: IndexedDB-backed storage using `localforage` for seamless offline access and fast performance.
- **📱 Responsive & Dark-Themed**: Sleek modern UI built with Framer Motion animations.

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **Framer Motion** (Fluid animations & transitions)
- **React Icons**
- **React Dropzone**
- **LocalForage** (IndexedDB client storage)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
git clone https://github.com/Om-Meena-UI/meme-vault.git
cd meme-vault
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:8000/](http://localhost:8000/) in your browser.
